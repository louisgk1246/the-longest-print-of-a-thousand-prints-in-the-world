# the-longest-print-of-a-thousand-prints-in-the-world
This is a personal project to see how far the limits go. 

The objective is to achieve the most extensive code possible using only 1000 prints, 1000 lines of comments, and approximately a maximum of 24 hours. 

The file executor.exe is the already compiled code of core.py, ready to run. 

I invite everyone who wants to try to surpass me.
